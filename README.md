# MASS UP · วิธีติดตั้งบนมือถือ (GitHub Pages, ฟรี)

ไฟล์ในโฟลเดอร์นี้ต้องอยู่ด้วยกันทั้งหมด:
`index.html`, `three.min.js`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `icon-maskable.png`

## 1. อัปขึ้น GitHub (ทำจากมือถือได้)
1. เข้า github.com แล้วล็อกอิน → กด **+** → **New repository**
2. ตั้งชื่อ เช่น `massup` → เลือก **Public** → กด **Create repository**
3. กด **uploading an existing file** → เลือกไฟล์ทั้ง 7 ไฟล์ (ต้องอยู่ชั้นนอกสุด ห้ามใส่ในโฟลเดอร์ย่อย) → **Commit changes**
4. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**
5. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/massup/`

## 2. ติดตั้งเป็นแอป
เปิดลิงก์ใน **Chrome** บน Android → เมนู ⋮ → **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**
เปิดครั้งแรกตอนมีเน็ต 1 ครั้ง หลังจากนั้นใช้ได้แม้ไม่มีเน็ต

## 3. อัปเดตเวอร์ชันใหม่
อัปโหลดไฟล์ใหม่ทับใน repo เดิม แล้วปิด-เปิดแอป 2 รอบ ข้อมูลเดิมไม่หาย
(ถ้าแก้ `three.min.js` หรือไอคอน ให้เปลี่ยน `VERSION` ใน `sw.js` ด้วย)

## ข้อควรรู้
- ข้อมูลและรูปทั้งหมดเก็บใน Chrome ของเครื่องนี้เท่านั้น ไม่อัปโหลดไปไหน
- ถ้าล้างข้อมูล Chrome หรือเปลี่ยนเครื่อง ข้อมูลจะหาย → **เพิ่มเติม → ตั้งค่า & สำรอง → สำรองข้อมูล** ทุกสัปดาห์
- Repo แบบ Public คนอื่นเห็นแค่ตัวโค้ดแอป ไม่เห็นข้อมูลของคุณ
